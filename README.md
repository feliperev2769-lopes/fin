# Controle Financeiro

App web de controle financeiro pessoal (PWA).

- Interface em `index.html`.
- Nenhum dado financeiro ou pessoal fica embutido no código.
- Os registros são carregados e salvos no arquivo Excel do usuário via File System Access API.
- Entre sessões, o app começa vazio: a planilha é a única fonte de verdade.
